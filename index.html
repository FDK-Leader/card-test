실시간 기록

    ※ 오더 앱의 안드로이드 USB 권한은 브라우저에서 읽을 수 없습니다. 리더기를 뽑았다 꽂을 때 허용 팝업이 다시 뜨면 "항상 허용"이 미설정입니다.

    ※ 시뮬레이션 결과입니다. 실제 장치를 점검한 것이 아닙니다.

    VAN 앱 "항상 열기" 점검 (안드로이드 팝업)

    이 설정은 안드로이드가 관리해서 웹에서 직접 읽을 수 없습니다. 대신 리더기를 다시 꽂았을 때 일어나는 일로 판단합니다. 팝업이 다시 뜨면 미적용, 팝업 없이 VAN 앱이 바로 열리면 적용입니다.

    교차 확인: 안드로이드 설정 → 앱 → VAN 앱 → "기본값으로 열기"(또는 기본 설정 지우기)에서 USB 기본값 설정 여부를 볼 수 있습니다. 메뉴 이름은 기기마다 다릅니다.

    허용된 장치 관리 (브라우저 권한)

    이 사이트에 저장된 USB 허용 목록입니다. 허용 시작일은 브라우저가 알려주지 않아 이 도구가 처음 확인한 날부터 기록합니다. 안드로이드 앱 권한과는 별개입니다.

    설정·예방 팁
    • 리더기 연결 팝업에서 "항상 이 앱에 허용" 선택 (뽑았다 꽂아 팝업이 다시 뜨면 미설정)
    • 오더 앱 배터리 사용량을 제한 없음으로, 절전 모드는 해제
    • 충전과 데이터가 동시에 되는 PD 허브 사용
    • 케이블은 타이로 거치대에 고정, C타입 단자 먼지 제거
